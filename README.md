# Token-Gap---Resort

A mobile resort-building and management game developed in Unity.

## Unity Version

- **Unity Editor:** 6000.6.6f1
- **Platform:** Mobile

## How to Open the Project

1. Clone or download the repository from GitHub.
2. Open Unity Hub.
3. Click **Add -> Add project from disk**.
4. Select the downloaded project folder.
5. Make sure Unity **6000.6.6f1** is installed.
6. Open the project in Unity Hub.
